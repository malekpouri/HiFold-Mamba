# 2026-10-21 — Phases 3–5: evaluation code, model, training loop

## Done and tested

- **Statistics** (`src/hifold/eval/stats.py`): 1 Mb blocks by window midpoint; seeds averaged before blocks; paired block bootstrap against the per-block best baseline; one-sided α = 0.025 with the 95 % percentile CI; Holm.
- **Structure** (`src/hifold/structure.py`): crossing-square insulation with g = exp(2 tanh(x/2)), computed via an integral image. It is differentiable, matches a brute-force check including NaNs, gives finite gradients with NaN pixels, and is rot180-equivariant. Also: boundary strength, AUROC, AP.
- **Model** (`src/hifold/model/`):
  - RCPS wrapper, tied RC LayerNorm and FiLM, aligned pooling.
  - Exact Mamba-1 selective scan in pure PyTorch: chunked, tested equal to the sequential reference.
  - BiMamba with tied weights, multi-scale mixer, paired biaffine head.
  - Parameters: paper config 3.32 M; 8 GB fallback 0.57 M.
- **Mandatory equivariance test** (`tests/test_equivariance.py`): **passes**. Covered:
  - fp32 (atol 1e-4, rtol 1e-5) and bf16 (rtol 1e-2);
  - eval mode, and train mode with and without checkpointing;
  - random and real hg38 sequence, several cells;
  - full 1,048,576 bp → 448×448 geometry;
  - a negative control showing the test detects a broken head.
- **Training loop** (`src/hifold/train.py`): AdamW, warmup + cosine, bf16 autocast, gradient accumulation, EMA, ±11 bp shift, stage-2 insulation loss, checkpoint selection on validation SCC, run directory with config hash, commit and versions.

## Finding 4 — the shared distance bias cannot express cell-specific distance profiles

On a synthetic target with a cell-specific distance profile, training converges to exactly the variance of the cell-specific part (0.011). Per-bin features carry no position information, and b_|i−j| is shared, so FiLM cannot create cell-specific P(s).

Real data needs this: the five lines mix Micro-C and Hi-C, and the targets keep a line-specific residual distance trend (P(s) plot in `notes/figures/`).

Added `cell_dist_bias` (b_{c,|i−j|}; 5 × 512 parameters; still RC-safe). It defaults to **off** to match `docs/architecture.md`. **Awaiting user approval** to make it the default.
